# 2.9: Angebotsvergleiche bei Beschaffungsmaßnahmen durchführen

**Kurz-Definition:**
Angebotsvergleiche bei Beschaffungsmaßnahmen sind systematische Verfahren zur Bewertung und Auswahl von Lieferanten, Produkten oder Dienstleistungen. Sie helfen, die beste Lösung hinsichtlich Preis, Qualität, Leistung und anderen Kriterien zu finden.

**Tabellarische Übersicht:**

| Aspekt | Beschreibung | Bedeutung |
|--------|--------------|-----------|
| **Quantitative Vergleiche** | Zahlenbasierte Bewertung (Preis, Leistung) | Objektive Entscheidungsgrundlage |
| **Qualitative Vergleiche** | Bewertung nicht messbarer Kriterien | Ganzheitliche Betrachtung |
| **Nutzwertanalyse** | Gewichtete Bewertung mehrerer Kriterien | Strukturierte Entscheidungsfindung |
| **Beschaffungsprozess** | Systematisches Vorgehen von Bedarf bis Lieferung | Effiziente Beschaffung |
| **Vertragsarten** | Verschiedene Vertragstypen verstehen | Rechtssichere Beschaffung |

**Visuelle Darstellung:**
```
Angebotsvergleich-Prozess:
    Bedarfsermittlung
         ↓
    Angebotsanfrage (Ausschreibung)
         ↓
    Angebotseingang
         ↓
    Angebotsvergleich
         ├── Quantitativ (Preis, Leistung)
         ├── Qualitativ (Service, Support)
         └── Nutzwertanalyse (gewichtet)
         ↓
    Entscheidung
         ↓
    Vertragsabschluss
         ↓
    Lieferung und Abnahme
```

**Praxis-Beispiel:**
Ein Unternehmen benötigt 20 neue Arbeitsplatz-PCs:
1. **Bedarfsermittlung:** Anforderungen definieren (CPU, RAM, Speicher, Software)
2. **Angebotsanfrage:** 3 Lieferanten anfragen (Lieferant A, B, C)
3. **Angebotseingang:** 
   - Lieferant A: 15.000€, Lieferzeit 2 Wochen, 3 Jahre Garantie
   - Lieferant B: 14.500€, Lieferzeit 3 Wochen, 2 Jahre Garantie
   - Lieferant C: 16.000€, Lieferzeit 1 Woche, 5 Jahre Garantie
4. **Vergleich:** Quantitativ (Preis), qualitativ (Lieferzeit, Garantie, Service)
5. **Entscheidung:** Nutzwertanalyse führt zu Lieferant A (beste Balance)

**Prüfungscheck:**
**Frage:** Welche Methoden stehen für Angebotsvergleiche zur Verfügung?

**Antwort:**
1. **Quantitative Vergleiche:** Zahlenbasierte Bewertung von Preis, Leistung, Lieferzeit
2. **Qualitative Vergleiche:** Bewertung von Service, Support, Reputation, Zuverlässigkeit
3. **Nutzwertanalyse:** Gewichtete Bewertung mehrerer Kriterien mit Punkten
4. **TCO-Analyse:** Gesamtkosten über Lebenszyklus betrachten
5. **Referenzen prüfen:** Erfahrungen anderer Kunden einbeziehen

**Merksatz:**
"Angebotsvergleich = Quantitativ + Qualitativ + Nutzwertanalyse - systematisch zum besten Angebot!"

## 2.9.1: Beschaffungsprozess und Beschaffungsplanung erläutern

**Kurz-Definition:**
Der Beschaffungsprozess umfasst alle Schritte von der Bedarfsermittlung bis zur Lieferung und Abnahme. Die Beschaffungsplanung strukturiert diesen Prozess und sorgt für rechtzeitige und kostengünstige Beschaffung.

**Tabellarische Übersicht:**

| Phase | Beschreibung | Aktivitäten |
|-------|--------------|-------------|
| **Bedarfsermittlung** | Was wird benötigt? | Anforderungen definieren, Spezifikationen erstellen |
| **Beschaffungsplanung** | Wann und wie beschaffen? | Zeitplan, Budget, Beschaffungsart festlegen |
| **Marktanalyse** | Welche Anbieter gibt es? | Lieferanten recherchieren, Markt vergleichen |
| **Angebotsanfrage** | Angebote einholen | Ausschreibung, Angebotsanfrage versenden |
| **Angebotsbewertung** | Angebote vergleichen | Quantitative/qualitative Vergleiche, Nutzwertanalyse |
| **Entscheidung** | Bestes Angebot wählen | Entscheidung treffen, Lieferant auswählen |
| **Bestellung** | Vertrag abschließen | Bestellung aufgeben, Vertrag unterzeichnen |
| **Lieferung** | Ware/Leistung erhalten | Lieferung entgegennehmen, prüfen |
| **Abnahme** | Qualität prüfen | Abnahme durchführen, Mängel melden |
| **Zahlung** | Rechnung begleichen | Rechnung prüfen, Zahlung veranlassen |

**Beschaffungsarten:**

| Art | Beschreibung | Vorteil | Nachteil |
|-----|--------------|---------|----------|
| **Einzelbeschaffung** | Einzelne Beschaffung bei Bedarf | Flexibel, keine Lagerkosten | Höhere Preise, längere Lieferzeiten |
| **Vorratsbeschaffung** | Beschaffung auf Lager | Schnelle Verfügbarkeit | Lagerkosten, Kapitalbindung |
| **Just-in-Time (JIT)** | Beschaffung genau bei Bedarf | Keine Lagerkosten, frische Ware | Abhängigkeit von Lieferanten |
| **Fremdbeschaffung** | Externe Lieferanten | Spezialisierung, keine Produktion | Abhängigkeit, Transportkosten |
| **Eigenfertigung** | Selbst produzieren | Unabhängigkeit, Qualitätskontrolle | Hohe Investition, Know-how nötig |

**Beschaffungsstrategien:**

| Strategie | Beschreibung | Anwendung |
|-----------|--------------|-----------|
| **Single Sourcing** | Ein Lieferant für alle Beschaffungen | Starke Partnerschaft, bessere Konditionen |
| **Multiple Sourcing** | Mehrere Lieferanten | Risikostreuung, Wettbewerb |
| **Global Sourcing** | Beschaffung weltweit | Günstige Preise, große Auswahl |
| **Local Sourcing** | Regionale Beschaffung | Kurze Lieferzeiten, Umweltschutz |

**Visuelle Darstellung:**
```
Beschaffungsprozess:
┌─────────────────────┐
│  Bedarfsermittlung  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Beschaffungsplanung │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│    Marktanalyse     │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  Angebotsanfrage    │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Angebotsbewertung   │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     Entscheidung    │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│      Bestellung      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│      Lieferung      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       Abnahme       │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       Zahlung       │
└─────────────────────┘
```

**Praxis-Beispiel:**
Ein IT-Unternehmen benötigt einen neuen Server:

**Phase 1: Bedarfsermittlung**
- Anforderungen: 32 GB RAM, 2 TB SSD, Windows Server 2022, 24/7 Support
- Budget: 15.000€
- Zeitrahmen: Installation in 4 Wochen

**Phase 2: Beschaffungsplanung**
- Beschaffungsart: Fremdbeschaffung (keine Eigenfertigung möglich)
- Strategie: Multiple Sourcing (3 Anbieter anfragen)
- Zeitplan: Angebote in 1 Woche, Entscheidung in 2 Wochen, Lieferung in 4 Wochen

**Phase 3: Marktanalyse**
- Recherche: 5 potenzielle Lieferanten identifiziert
- Auswahl: 3 Lieferanten für Angebotsanfrage ausgewählt

**Phase 4: Angebotsanfrage**
- Ausschreibung mit detaillierten Spezifikationen versendet
- Frist: 1 Woche

**Phase 5: Angebotsbewertung**
- Lieferant A: 14.500€, Lieferzeit 3 Wochen, guter Support
- Lieferant B: 13.800€, Lieferzeit 4 Wochen, durchschnittlicher Support
- Lieferant C: 15.200€, Lieferzeit 2 Wochen, exzellenter Support

**Phase 6: Entscheidung**
- Nutzwertanalyse: Lieferant A gewinnt (beste Balance)

**Phase 7: Bestellung**
- Bestellung bei Lieferant A aufgegeben
- Vertrag unterzeichnet

**Phase 8: Lieferung**
- Server wird geliefert
- Verpackung und Lieferzustand geprüft

**Phase 9: Abnahme**
- Funktionstest durchgeführt
- Abnahme bestätigt

**Phase 10: Zahlung**
- Rechnung geprüft
- Zahlung veranlasst

**Prüfungscheck:**
**Frage:** Beschreiben Sie die Phasen des Beschaffungsprozesses und nennen Sie verschiedene Beschaffungsarten.

**Antwort:**
**Phasen des Beschaffungsprozesses:**
1. **Bedarfsermittlung:** Was wird benötigt? Anforderungen definieren
2. **Beschaffungsplanung:** Wann und wie beschaffen? Zeitplan und Strategie festlegen
3. **Marktanalyse:** Welche Anbieter gibt es? Lieferanten recherchieren
4. **Angebotsanfrage:** Angebote einholen (Ausschreibung)
5. **Angebotsbewertung:** Angebote vergleichen und bewerten
6. **Entscheidung:** Bestes Angebot auswählen
7. **Bestellung:** Vertrag abschließen
8. **Lieferung:** Ware/Leistung erhalten
9. **Abnahme:** Qualität prüfen
10. **Zahlung:** Rechnung begleichen

**Beschaffungsarten:**
- **Einzelbeschaffung:** Bei Bedarf einzeln beschaffen
- **Vorratsbeschaffung:** Auf Lager beschaffen
- **Just-in-Time (JIT):** Genau bei Bedarf beschaffen
- **Fremdbeschaffung:** Externe Lieferanten nutzen
- **Eigenfertigung:** Selbst produzieren

**Merksatz:**
"Beschaffungsprozess = Bedarf → Planung → Analyse → Anfrage → Bewertung → Entscheidung → Bestellung → Lieferung → Abnahme → Zahlung!"

## 2.9.2: Quantitative Angebotsvergleiche vornehmen

**Kurz-Definition:**
Quantitative Angebotsvergleiche bewerten Angebote anhand messbarer, zahlenbasierter Kriterien wie Preis, Leistung, Lieferzeit, Garantiezeit und technische Spezifikationen.

**Tabellarische Übersicht:**

| Kriterium | Beschreibung | Bewertung |
|-----------|--------------|-----------|
| **Preis** | Anschaffungspreis, Gesamtkosten | Niedriger = besser |
| **Leistung** | Technische Spezifikationen (CPU, RAM, etc.) | Höher = besser |
| **Lieferzeit** | Zeit bis zur Lieferung | Kürzer = besser |
| **Garantie** | Garantiezeit, Garantiebedingungen | Länger = besser |
| **Wartungskosten** | Jährliche Wartungskosten | Niedriger = besser |
| **Energieverbrauch** | Stromverbrauch, Effizienz | Niedriger = besser |
| **Lebensdauer** | Erwartete Nutzungsdauer | Länger = besser |

**Vergleichsmethoden:**

| Methode | Beschreibung | Anwendung |
|---------|--------------|-----------|
| **Direkter Preisvergleich** | Einfacher Preisvergleich | Schnelle Entscheidung bei gleicher Leistung |
| **Preis-Leistungs-Verhältnis** | Preis pro Leistungseinheit | Vergleich bei unterschiedlichen Leistungen |
| **Gesamtkostenvergleich (TCO)** | Alle Kosten über Lebenszyklus | Langfristige Entscheidungen |
| **Kosten-Nutzen-Analyse** | Verhältnis von Kosten zu Nutzen | Wirtschaftlichkeitsbetrachtung |

**Vergleichstabelle (Beispiel):**

| Kriterium | Angebot A | Angebot B | Angebot C | Gewinner |
|-----------|-----------|-----------|-----------|----------|
| **Preis** | 10.000€ | 9.500€ | 11.000€ | B |
| **CPU (GHz)** | 3,5 | 3,2 | 3,8 | C |
| **RAM (GB)** | 32 | 32 | 64 | C |
| **Lieferzeit (Wochen)** | 2 | 3 | 1 | C |
| **Garantie (Jahre)** | 3 | 2 | 5 | C |
| **Wartung/Jahr** | 500€ | 600€ | 400€ | C |

**Visuelle Darstellung:**
```
Quantitativer Vergleich:
    Angebot A
         ├── Preis: 10.000€
         ├── Leistung: 85 Punkte
         ├── Lieferzeit: 2 Wochen
         └── Garantie: 3 Jahre
              =
         Gesamtbewertung: 75 Punkte

    Angebot B
         ├── Preis: 9.500€
         ├── Leistung: 80 Punkte
         ├── Lieferzeit: 3 Wochen
         └── Garantie: 2 Jahre
              =
         Gesamtbewertung: 70 Punkte

    Angebot C
         ├── Preis: 11.000€
         ├── Leistung: 95 Punkte
         ├── Lieferzeit: 1 Woche
         └── Garantie: 5 Jahre
              =
         Gesamtbewertung: 85 Punkte

→ Angebot C gewinnt
```

**Praxis-Beispiel:**
Vergleich von 3 Server-Angeboten:

**Angebot A:**
- Preis: 12.000€
- CPU: Intel Xeon 3,4 GHz (8 Kerne)
- RAM: 64 GB DDR4
- Speicher: 2 TB SSD
- Lieferzeit: 3 Wochen
- Garantie: 3 Jahre
- Wartung: 800€/Jahr
- Energieverbrauch: 200 W

**Angebot B:**
- Preis: 11.500€

- RAM: 64 GB DDR4
- Speicher: 1,5 TB SSD
- Lieferzeit: 4 Wochen
- Garantie: 2 Jahre
- Wartung: 900€/Jahr
- Energieverbrauch: 180 W

**Angebot C:**
- Preis: 13.000€
- CPU: Intel Xeon 3,6 GHz (10 Kerne)
- RAM: 128 GB DDR4
- Speicher: 2 TB SSD
- Lieferzeit: 2 Wochen
- Garantie: 5 Jahre
- Wartung: 600€/Jahr

**Quantitativer Vergleich:**

| Kriterium | Gewichtung | A | B | C | Beste |
|-----------|------------|---|---|---|-------|
| **Preis** | 30% | 12.000€ | 11.500€ | 13.000€ | B |
| **CPU-Leistung** | 20% | 8 Kerne | 6 Kerne | 10 Kerne | C |

**Bewertung (Punkte 1-10):**

|-----------|---|---|---|
| Preis | 7 | 8 | 6 |
| CPU | 7 | 6 | 9 |
| RAM | 7 | 7 | 10 |
| Speicher | 9 | 7 | 9 |
| Lieferzeit | 7 | 6 | 9 |
| Garantie | 7 | 6 | 10 |
| Wartung | 7 | 6 | 9 |
| **Gesamt (gewichtet)** | **7,2** | **7,0** | **8,1** |

**Ergebnis:** Angebot C gewinnt mit 8,1 Punkten (beste Leistung, schnellste Lieferung, längste Garantie)

| **RAM** | 30% | 16 GB | 16 GB | 32 GB | C |
| **Lieferzeit** | 15% | 2 Wo | 3 Wo | 1 Wo | C |
| **Garantie** | 15% | 2 Jahre | 3 Jahre | 3 Jahre | B/C |

**Bewertung (Punkte 1-10):**

| Kriterium | A | B | C |
|-----------|---|---|---|
| Preis | 7 | 8 | 6 |
| RAM | 6 | 6 | 10 |
| Lieferzeit | 8 | 6 | 10 |
| Garantie | 6 | 9 | 9 |
| **Gesamt (gewichtet)** | **6,8** | **7,4** | **7,8** |

**Ergebnis:** Angebot C gewinnt mit 7,8 Punkten (doppelt so viel RAM, schnellste Lieferzeit, gute Garantie)

**Merksatz:**
"Quantitativer Vergleich = Zahlen vergleichen - Preis, Leistung, Zeit, Garantie objektiv bewerten!"

## 2.9.3: Nutzwertanalysen durchführen

**Kurz-Definition:**
Die Nutzwertanalyse ist eine strukturierte Methode zur Bewertung von Alternativen anhand mehrerer Kriterien. Jedes Kriterium wird gewichtet und mit Punkten bewertet, um eine objektive Entscheidungsgrundlage zu schaffen.

**Tabellarische Übersicht:**

| Schritt | Beschreibung | Bedeutung |
|---------|--------------|-----------|
| **Kriterien definieren** | Relevante Bewertungskriterien festlegen | Vollständige Bewertung |
| **Gewichtung** | Wichtigkeit der Kriterien festlegen | Prioritäten setzen |
| **Bewertung** | Punkte für jede Alternative vergeben | Objektive Bewertung |
| **Berechnung** | Gewichtete Punkte berechnen | Vergleichbare Werte |
| **Vergleich** | Gesamtpunktzahl vergleichen | Beste Alternative finden |

**Bewertungsskala:**

| Punkte | Bedeutung | Beschreibung |
|--------|-----------|--------------|
| **10** | Sehr gut | Übertrifft alle Erwartungen |
| **8** | Gut | Erfüllt alle Anforderungen sehr gut |
| **6** | Befriedigend | Erfüllt alle Anforderungen |
| **4** | Ausreichend | Erfüllt grundlegende Anforderungen |
| **2** | Mangelhaft | Erfüllt Anforderungen nur teilweise |
| **0** | Ungenügend | Erfüllt Anforderungen nicht |

**Gewichtungsmethoden:**

| Methode | Beschreibung | Beispiel |
|---------|--------------|----------|
| **Prozentuale Gewichtung** | Kriterien in Prozent gewichten (Summe = 100%) | Preis 40%, Leistung 30%, Service 30% |
| **Punktegewichtung** | Kriterien mit Punkten gewichten | Preis 4 Punkte, Leistung 3 Punkte, Service 3 Punkte |
| **Paarweiser Vergleich** | Kriterien paarweise vergleichen | Preis wichtiger als Service? |

**Visuelle Darstellung:**
```
Nutzwertanalyse-Prozess:
┌──────────────────────┐
│ Kriterien definieren  │
│ (Preis, Leistung,     │
│  Service, etc.)       │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│   Gewichtung         │
│   (Wichtigkeit %)    │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│   Bewertung          │
│   (Punkte 0-10)      │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│   Berechnung         │
│   (Gewicht × Punkte) │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│   Vergleich          │
│   (Gesamtpunktzahl)  │
└──────────────────────┘
```

**Praxis-Beispiel:**
Nutzwertanalyse für die Auswahl eines neuen Servers:

**Schritt 1: Kriterien definieren**
- Preis
- CPU-Leistung
- RAM
- Speicherkapazität
- Lieferzeit
- Garantie
- Support-Qualität
- Energieeffizienz

**Schritt 2: Gewichtung festlegen**

| Kriterium | Gewichtung | Begründung |
|-----------|------------|------------|

**Ergebnis:** Angebot C gewinnt mit 8,30 Punkten (doppelt so viel RAM, schnellste Lieferzeit, gute Garantie)

**Merksatz:**
"Nutzwertanalyse = Kriterien definieren → gewichten → bewerten → berechnen → vergleichen - strukturiert entscheiden!"

## 2.9.4: Vertragsarten und AGB unterscheiden

**Kurz-Definition:**
Vertragsarten unterscheiden sich in ihren Regelungen zu Leistung, Preis, Risiko und Haftung. AGB (Allgemeine Geschäftsbedingungen) sind vorformulierte Vertragsbedingungen, die für viele Verträge gelten.

**Tabellarische Übersicht:**

| Vertragsart | Beschreibung | Besonderheiten |
|-------------|--------------|----------------|
| **Werklieferungsvertrag** | Herstellung/Beschaffung + Lieferung | Hersteller haftet für Mängel |
| **Kaufvertrag** | Übertragung von Eigentum gegen Geld | Gewährleistung bei Mängeln |
| **Werkvertrag** | Herstellung eines Werks (Erfolg geschuldet) | Erfolg muss erreicht werden |
| **Dienstleistungsvertrag** | Erbringung von Dienstleistungen | Tätigkeit geschuldet, nicht Erfolg |
| **Mietvertrag** | Überlassung zur Nutzung | Zeitlich begrenzt |
| **Leasingvertrag** | Finanzierung + Nutzung | Option auf Kauf |

**Vertragsarten im Detail:**

**1. Werklieferungsvertrag (§ 651 BGB)**
- **Definition:** Kombination aus Werkvertrag und Kaufvertrag
- **Anwendung:** Individuell gefertigte oder beschaffte bewegliche Sachen
- **Beispiel:** Server nach Spezifikation beschaffen und liefern
- **Haftung:** Hersteller/Lieferant haftet für Mängel
- **Besonderheit:** Kann nicht vor Lieferung zurückgetreten werden

**2. Kaufvertrag (§ 433 BGB)**
- **Definition:** Übertragung von Eigentum gegen Geld
- **Anwendung:** Standardware, fertige Produkte
- **Beispiel:** Kauf eines Standard-PCs
- **Gewährleistung:** 2 Jahre bei neuen, 1 Jahr bei gebrauchten Sachen
- **Rechte:** Mängelbeseitigung, Minderung, Rücktritt

**3. Werkvertrag (§ 631 BGB)**
- **Definition:** Herstellung eines Werks gegen Vergütung
- **Anwendung:** Installation, Programmierung, Wartung
- **Beispiel:** Netzwerkinstallation, Softwareentwicklung
- **Erfolg geschuldet:** Werk muss funktionieren
- **Haftung:** 5 Jahre bei Bauwerken, sonst 2 Jahre

**4. Dienstleistungsvertrag (§ 611 BGB)**
- **Definition:** Erbringung von Dienstleistungen gegen Vergütung
- **Anwendung:** Beratung, Support, Schulung
- **Beispiel:** IT-Beratung, Support-Hotline
- **Tätigkeit geschuldet:** Erfolg nicht garantiert
- **Haftung:** Bei Sorgfaltspflichtverletzung

**AGB (Allgemeine Geschäftsbedingungen):**

| Aspekt | Beschreibung | Bedeutung |
|--------|--------------|-----------|
| **Definition** | Vorformulierte Vertragsbedingungen | Standardisierung |
| **Geltungsbereich** | Für viele Verträge gleich | Zeitersparnis |
| **Inhaltskontrolle** | AGB-Gesetz prüft auf Unwirksamkeit | Verbraucherschutz |
| **Einbeziehung** | Muss dem Vertragspartner bekannt sein | Transparenz |
| **Unwirksame Klauseln** | Überraschende oder benachteiligende Klauseln | Rechtsschutz |

**Wichtige AGB-Klauseln:**

| Klausel | Beschreibung | Rechtliche Bewertung |
|---------|--------------|----------------------|
| **Haftungsausschluss** | Haftung begrenzen oder ausschließen | Teilweise unwirksam |
| **Preisänderungsvorbehalt** | Preise nachträglich ändern | Bei Verbrauchern unwirksam |
| **Zahlungsbedingungen** | Zahlungsfristen, Skonto | Zulässig |
| **Lieferbedingungen** | Lieferzeit, Versandkosten | Zulässig |
| **Gewährleistungsausschluss** | Gewährleistung ausschließen | Bei Verbrauchern unwirksam |
| **Gerichtsstand** | Zuständiges Gericht festlegen | Zulässig |

**Visuelle Darstellung:**
```
Vertragsarten:
    Werklieferungsvertrag
         ├── Herstellung + Lieferung
         └── Haftung für Mängel

    Kaufvertrag
         ├── Eigentumsübertragung
         └── Gewährleistung 2 Jahre

    Werkvertrag
         ├── Erfolg geschuldet
         └── Haftung 2-5 Jahre

    Dienstleistungsvertrag
         ├── Tätigkeit geschuldet
         └── Haftung bei Sorgfaltspflichtverletzung

AGB:
    Vorformulierte Bedingungen
         ├── Einbeziehung erforderlich
         ├── Inhaltskontrolle
         └── Unwirksame Klauseln möglich
```

**Praxis-Beispiel 1: Vertragsart bestimmen**

**Fall 1: Server-Kauf**
- **Sachverhalt:** Unternehmen kauft Standard-Server aus Katalog
- **Vertragsart:** Kaufvertrag
- **Begründung:** Fertiges Produkt, Eigentumsübertragung
- **Rechte:** 2 Jahre Gewährleistung, Mängelbeseitigung

**Fall 2: Individueller Server**
- **Sachverhalt:** Server nach Spezifikation beschaffen und liefern
- **Vertragsart:** Werklieferungsvertrag
- **Begründung:** Individuell beschafft, Herstellung + Lieferung
- **Rechte:** Haftung für Mängel, kann nicht vor Lieferung zurücktreten

**Fall 3: Netzwerkinstallation**
- **Sachverhalt:** Netzwerk wird installiert und konfiguriert
- **Vertragsart:** Werkvertrag
- **Begründung:** Erfolg geschuldet (funktionierendes Netzwerk)
- **Rechte:** 2 Jahre Haftung, Mängelbeseitigung

**Fall 4: IT-Beratung**
- **Sachverhalt:** Berater gibt Empfehlungen zur IT-Strategie
- **Vertragsart:** Dienstleistungsvertrag
- **Begründung:** Tätigkeit geschuldet, nicht Erfolg
- **Rechte:** Haftung nur bei Sorgfaltspflichtverletzung

**Praxis-Beispiel 2: AGB prüfen**

**AGB-Klausel 1:**
"Die Gewährleistung wird ausgeschlossen."

- **Bewertung:** Bei Verbrauchern unwirksam (§ 309 BGB)
- **Bei Unternehmen:** Teilweise zulässig, aber nicht für Vorsatz und grobe Fahrlässigkeit

**AGB-Klausel 2:**
"Der Verkäufer haftet nicht für Schäden, es sei denn, sie beruhen auf Vorsatz oder grober Fahrlässigkeit."

- **Bewertung:** Zulässig bei Unternehmen
- **Bei Verbrauchern:** Unwirksam bei Personenschäden

**AGB-Klausel 3:**
"Preise können nachträglich geändert werden."

- **Bewertung:** Bei Verbrauchern unwirksam
- **Bei Unternehmen:** Möglich bei veränderlichen Kosten (z.B. Rohstoffe)

**Prüfungscheck:**
**Frage:** Erklären Sie die Unterschiede zwischen Kaufvertrag, Werkvertrag und Dienstleistungsvertrag. Nennen Sie Beispiele für jede Vertragsart.

**Antwort:**
**Kaufvertrag:**
- **Definition:** Übertragung von Eigentum gegen Geld
- **Anwendung:** Standardware, fertige Produkte
- **Beispiel:** Kauf eines Standard-PCs, Standard-Software
- **Gewährleistung:** 2 Jahre bei neuen, 1 Jahr bei gebrauchten Sachen
- **Rechte:** Mängelbeseitigung, Minderung, Rücktritt

**Werkvertrag:**
- **Definition:** Herstellung eines Werks gegen Vergütung
- **Anwendung:** Installation, Programmierung, Wartung
- **Beispiel:** Netzwerkinstallation, Softwareentwicklung, Server-Installation
- **Erfolg geschuldet:** Werk muss funktionieren
- **Haftung:** 5 Jahre bei Bauwerken, sonst 2 Jahre

**Dienstleistungsvertrag:**
- **Definition:** Erbringung von Dienstleistungen gegen Vergütung
- **Anwendung:** Beratung, Support, Schulung
- **Beispiel:** IT-Beratung, Support-Hotline, Schulungen
- **Tätigkeit geschuldet:** Erfolg nicht garantiert, nur Tätigkeit
- **Haftung:** Bei Sorgfaltspflichtverletzung

**Merksatz:**
"Kaufvertrag = Eigentum, Werkvertrag = Erfolg, Dienstleistung = Tätigkeit - die richtige Vertragsart wählen!"

## 2.10: Lieferung, Installation und Übergabe vornehmen

**Kurz-Definition:**
Die Lieferung, Installation und Übergabe umfasst alle Schritte von der Anlieferung der Ware bis zur finalen Abnahme und Übergabe an den Kunden. Dabei müssen Arbeitssicherheit, IT-Sicherheit und rechtliche Vorgaben beachtet werden.

**Tabellarische Übersicht:**

| Phase | Beschreibung | Aktivitäten |
|-------|--------------|-------------|
| **Vorbereitung** | Abnahme vorbereiten | Checklisten, Termine, Räume vorbereiten |
| **Lieferung** | Ware erhalten | Lieferung prüfen, Verpackung kontrollieren |
| **Installation** | System einrichten | Hardware installieren, Software konfigurieren |
| **Prüfung** | Funktionstest | System testen, Dokumentation prüfen |
| **Abnahme** | Finale Abnahme | Abnahmeprotokoll, Mängel dokumentieren |
| **Übergabe** | An Kunden übergeben | Schulung, Dokumentation, Support-Informationen |

**Visuelle Darstellung:**
```
Lieferung-Installation-Übergabe-Prozess:
    Vorbereitung
         ├── Checklisten erstellen
         ├── Termine koordinieren
         └── Räume vorbereiten
         ↓
    Lieferung
         ├── Ware erhalten
         ├── Verpackung prüfen
         └── Lieferzustand dokumentieren
         ↓
    Installation
         ├── Hardware installieren
         ├── Software konfigurieren
         └── Netzwerk einbinden
         ↓
    Prüfung
         ├── Funktionstest
         ├── Performance-Test
         └── Dokumentation prüfen
         ↓
    Abnahme
         ├── Abnahmeprotokoll
         ├── Mängel dokumentieren
         └── Abnahme bestätigen
         ↓
    Übergabe
         ├── Schulung durchführen
         ├── Dokumentation übergeben
         └── Support-Informationen
```

**Praxis-Beispiel:**
Server-Installation in einem Unternehmen:

**Phase 1: Vorbereitung**
- Checkliste erstellt (Hardware, Software, Netzwerk)
- Termin mit Kunde vereinbart (2 Wochen nach Bestellung)
- Serverraum vorbereitet (Strom, Kühlung, Platz)
- Zugangsberechtigungen geklärt

**Phase 2: Lieferung**
- Server wird geliefert
- Verpackung geprüft (unbeschädigt)
- Lieferzustand dokumentiert (Fotos)
- Lieferung quittiert

**Phase 3: Installation**
- Server im Serverraum aufgestellt
- Strom angeschlossen
- Netzwerkverbindung hergestellt
- Betriebssystem installiert (Windows Server 2022)
- Konfiguration durchgeführt (Domain, Benutzer, Dienste)

**Phase 4: Prüfung**
- Funktionstest: Server startet, alle Dienste laufen
- Performance-Test: CPU, RAM, Festplatte OK
- Netzwerktest: Verbindung zum Netzwerk funktioniert
- Dokumentation geprüft (Installationsanleitung vorhanden)

**Phase 5: Abnahme**
- Abnahmeprotokoll erstellt
- Alle Funktionen getestet und dokumentiert
- Keine Mängel festgestellt
- Abnahme vom Kunden bestätigt

**Phase 6: Übergabe**
- Schulung für Administratoren durchgeführt
- Dokumentation übergeben (Installationsanleitung, Konfiguration)
- Support-Informationen übergeben (Hotline, Wartungsvertrag)
- Übergabe abgeschlossen

## 2.10.2: Arbeitssicherheit und Gesundheitsschutz bei der Arbeit gewährleisten

**Kurz-Definition:**
Arbeitssicherheit und Gesundheitsschutz umfassen alle Maßnahmen zum Schutz der Gesundheit und Sicherheit von Beschäftigten bei der Arbeit. Dies ist gesetzlich geregelt (ArbSchG, BetrSichV) und muss bei allen Tätigkeiten beachtet werden.

**Tabellarische Übersicht:**

| Aspekt | Beschreibung | Bedeutung |
|--------|--------------|-----------|
| **Gefährdungsbeurteilung** | Gefahren identifizieren und bewerten | Grundlage für Maßnahmen |
| **Schutzmaßnahmen** | Technische, organisatorische, persönliche Maßnahmen | Gefahren minimieren |
| **Persönliche Schutzausrüstung (PSA)** | Schutzausrüstung tragen | Individueller Schutz |
| **Unterweisung** | Mitarbeiter schulen | Bewusstsein schaffen |
| **Erste Hilfe** | Erste-Hilfe-Maßnahmen | Sofortmaßnahmen bei Unfällen |

**Gefährdungen in der IT:**

| Gefährdung | Beschreibung | Schutzmaßnahme |
|------------|--------------|---------------|
| **Elektrische Gefahren** | Stromschlag, Kurzschluss | Spannungsfreiheit, isolierte Werkzeuge |
| **Mechanische Gefahren** | Schnittverletzungen, Quetschungen | Vorsicht, geeignete Werkzeuge |
| **Ergonomische Gefahren** | Rückenprobleme, Augenbelastung | Ergonomische Arbeitsplätze |
| **Lärm** | Hörschäden | Gehörschutz, Lärmminderung |
| **Staub/Partikel** | Atemwegserkrankungen | Atemschutz, Absaugung |
| **Chemikalien** | Vergiftungen, Hautschäden | Handschuhe, Lüftung |
| **Brandgefahr** | Brände, Explosionen | Brandschutz, Fluchtwege |

**Persönliche Schutzausrüstung (PSA):**

| PSA | Anwendung | Schutz vor |
|-----|-----------|------------|
| **Sicherheitsschuhe** | Bei Installation, Transport | Quetschungen, Stürze |
| **Handschuhe** | Bei Arbeiten mit Kabeln, Chemikalien | Schnittverletzungen, Chemikalien |
| **Schutzbrille** | Bei Lötarbeiten, Schleifen | Augenverletzungen |
| **Gehörschutz** | Bei lauten Arbeiten | Hörschäden |
| **Atemschutz** | Bei Staub, Dämpfen | Atemwegserkrankungen |
| **Warnweste** | Auf Baustellen, Verkehrsbereichen | Sichtbarkeit |

**5-Punkte-Regel (Elektrische Arbeiten):**

1. **Freischalten:** Spannungsfreiheit herstellen
2. **Gegen Wiedereinschalten sichern:** Sicherung entfernen, abschließen
3. **Spannungsfreiheit feststellen:** Spannungsprüfer verwenden
4. **Erden und Kurzschließen:** Bei Hochspannung
5. **Benachbarte Teile abdecken:** Isolierung, Absperrung

**Visuelle Darstellung:**
```
Arbeitssicherheit:
    Gefährdungsbeurteilung
         ├── Gefahren identifizieren
         ├── Risiko bewerten
         └── Maßnahmen festlegen
         ↓
    Schutzmaßnahmen
         ├── Technisch (Abschirmung, Absaugung)
         ├── Organisatorisch (Arbeitsablauf, Pausen)
         └── Persönlich (PSA)
         ↓
    Unterweisung
         ├── Gefahren aufzeigen
         ├── Maßnahmen erklären
         └── Verhalten trainieren
         ↓
    Überwachung
         ├── Einhaltung prüfen
         ├── Verbesserungen suchen
         └── Dokumentation
```

**Praxis-Beispiel:**
Server-Installation im Serverraum:

**Gefährdungsbeurteilung:**
- **Elektrische Gefahren:** Stromschlag bei Arbeiten an Elektroinstallation
- **Mechanische Gefahren:** Quetschungen beim Transport schwerer Server
- **Ergonomische Gefahren:** Rückenbelastung beim Heben
- **Lärm:** Ventilatoren, Kühlung
- **Temperatur:** Hohe Temperaturen im Serverraum

**Schutzmaßnahmen:**

**Technisch:**
- Spannungsfreiheit vor Arbeiten herstellen (5-Punkte-Regel)
- Transportwagen für schwere Geräte verwenden
- Klimaanlage im Serverraum (Temperaturregelung)
- Lärmminderung durch Schalldämmung

**Organisatorisch:**
- Zwei Personen beim Transport schwerer Geräte
- Pausen bei anstrengenden Arbeiten
- Arbeitsplatzbeleuchtung sicherstellen
- Fluchtwege freihalten

**Persönlich (PSA):**
- Sicherheitsschuhe (S3) tragen
- Handschuhe bei Kabelarbeiten
- Keine losen Kleidungsstücke (Gefahr durch bewegliche Teile)

**Unterweisung:**
- Gefahren im Serverraum erklären
- Verhalten bei Notfällen (Brand, Stromunfall)
- Erste-Hilfe-Maßnahmen
- Fluchtwege zeigen

**Durchführung:**
1. **Vorbereitung:** PSA anlegen, Werkzeuge prüfen
2. **Freischalten:** Strom abschalten, gegen Wiedereinschalten sichern
3. **Spannungsfreiheit:** Spannungsprüfer verwenden
4. **Transport:** Zwei Personen, Transportwagen
5. **Installation:** Vorsichtig arbeiten, keine Eile
6. **Nacharbeit:** Aufräumen, PSA ablegen

**Prüfungscheck:**
**Frage:** Nennen Sie die wichtigsten Gefährdungen bei IT-Arbeiten und die entsprechenden Schutzmaßnahmen. Erklären Sie die 5-Punkte-Regel.

**Antwort:**
**Gefährdungen und Schutzmaßnahmen:**

1. **Elektrische Gefahren:**
   - Schutz: 5-Punkte-Regel, isolierte Werkzeuge, Spannungsprüfer

2. **Mechanische Gefahren:**
   - Schutz: Vorsicht, geeignete Werkzeuge, Transportwagen, zwei Personen

3. **Ergonomische Gefahren:**
   - Schutz: Ergonomische Arbeitsplätze, richtiges Heben, Pausen

4. **Lärm:**
   - Schutz: Gehörschutz, Lärmminderung, Schalldämmung

5. **Staub/Partikel:**
   - Schutz: Atemschutz, Absaugung, Lüftung

**5-Punkte-Regel (Elektrische Arbeiten):**
1. **Freischalten:** Spannungsfreiheit herstellen (Strom abschalten)
2. **Gegen Wiedereinschalten sichern:** Sicherung entfernen, abschließen, Warnschild
3. **Spannungsfreiheit feststellen:** Spannungsprüfer verwenden
4. **Erden und Kurzschließen:** Bei Hochspannung (nicht bei Niederspannung)
5. **Benachbarte Teile abdecken:** Isolierung, Absperrung

**Merksatz:**
"Arbeitssicherheit = Gefährdung erkennen → Maßnahmen treffen → PSA tragen → unterweisen - sicher arbeiten!"

## 2.10.3: Für IT-Sicherheit am Arbeitsplatz eine Risikoanalyse vorbereiten

**Kurz-Definition:**
Eine Risikoanalyse für IT-Sicherheit am Arbeitsplatz identifiziert Gefährdungen für die IT-Sicherheit, bewertet deren Risiko und schlägt Maßnahmen vor. Sie ist Grundlage für ein IT-Sicherheitskonzept.

**Tabellarische Übersicht:**

| Schritt | Beschreibung | Bedeutung |
|---------|--------------|-----------|
| **Gefährdungen identifizieren** | Mögliche Bedrohungen finden | Vollständige Analyse |
| **Risiko bewerten** | Eintrittswahrscheinlichkeit × Schadensausmaß | Prioritäten setzen |
| **Maßnahmen festlegen** | Schutzmaßnahmen definieren | Risiken minimieren |
| **Umsetzung planen** | Maßnahmen umsetzen | Praktische Umsetzung |
| **Überwachung** | Regelmäßige Überprüfung | Kontinuierliche Verbesserung |

**Gefährdungen am IT-Arbeitsplatz:**

| Gefährdung | Beschreibung | Beispiel |
|------------|--------------|----------|
| **Physischer Zugriff** | Unbefugter Zugriff auf Geräte | Offener PC, fehlende Zugangskontrolle |
| **Malware** | Schadsoftware | Viren, Trojaner, Ransomware |
| **Social Engineering** | Manipulation von Personen | Phishing, Pretexting |
| **Passwort-Schwächen** | Schwache Passwörter | Einfache Passwörter, Wiederverwendung |
| **Unverschlüsselte Daten** | Daten ohne Verschlüsselung | USB-Sticks, E-Mails |
| **Fehlende Updates** | Veraltete Software | Alte Betriebssysteme, fehlende Patches |
| **Unsichere Netzwerke** | Offene WLANs, unverschlüsselt | Öffentliches WLAN, fehlende Verschlüsselung |
| **Datenverlust** | Versehentliches Löschen | Keine Backups, fehlende Redundanz |

**Risikobewertung:**

| Risikostufe | Eintrittswahrscheinlichkeit | Schadensausmaß | Maßnahme |
|-------------|----------------------------|----------------|----------|
| **Hoch** | Hoch | Hoch | Sofortige Maßnahmen |
| **Mittel** | Mittel | Mittel | Geplante Maßnahmen |
| **Niedrig** | Niedrig | Niedrig | Überwachung |

**Risikomatrix:**

```
Schadensausmaß
    Hoch    │ Mittel │ Hoch
    Mittel  │ Niedrig│ Mittel
    Niedrig │ Niedrig│ Niedrig
            └────────┴────────
            Niedrig  Mittel  Hoch
         Eintrittswahrscheinlichkeit
```

**Visuelle Darstellung:**
```
Risikoanalyse-Prozess:
    Gefährdungen identifizieren
         ├── Physischer Zugriff
         ├── Malware
         ├── Social Engineering
         └── Technische Schwachstellen
         ↓
    Risiko bewerten
         ├── Eintrittswahrscheinlichkeit
         ├── Schadensausmaß
         └── Risikostufe
         ↓
    Maßnahmen festlegen
         ├── Technisch (Firewall, Verschlüsselung)
         ├── Organisatorisch (Richtlinien, Schulung)
         └── Personell (Awareness)
         ↓
    Umsetzung planen
         ├── Prioritäten setzen
         ├── Zeitplan
         └── Verantwortlichkeiten
         ↓
    Überwachung
         ├── Regelmäßige Prüfung
         ├── Anpassungen
         └── Dokumentation
```

**Praxis-Beispiel:**
Risikoanalyse für einen IT-Arbeitsplatz:

## 2.10.4: Abfall- und Recyclinggesetze beachten

**Kurz-Definition:**
Abfall- und Recyclinggesetze regeln die Entsorgung von Elektro- und Elektronikgeräten (ElektroG), Batterien (BattG) und Verpackungen (VerpackG). IT-Unternehmen müssen diese Gesetze bei der Entsorgung von IT-Geräten beachten.

**Tabellarische Übersicht:**

| Gesetz | Vollständiger Name | Regelungsbereich |
|--------|-------------------|------------------|
| **ElektroG** | Elektro- und Elektronikgerätegesetz | Entsorgung von Elektrogeräten |
| **BattG** | Batteriegesetz | Entsorgung von Batterien und Akkus |
| **VerpackG** | Verpackungsgesetz | Entsorgung von Verpackungen |
| **KrWG** | Kreislaufwirtschaftsgesetz | Abfallvermeidung, Recycling |
| **DSGVO** | Datenschutz-Grundverordnung | Datenlöschung vor Entsorgung |

**ElektroG (Elektro- und Elektronikgerätegesetz):**

| Kategorie | Beschreibung | Beispiele |
|-----------|--------------|-----------|
| **1. Wärmeübertrager** | Kühl- und Gefriergeräte | Server-Kühlung, Klimaanlagen |
| **2. Bildschirme** | Monitore, Displays | Monitore, Bildschirme |
| **3. Lampen** | Leuchtmittel | LED-Lampen, Leuchtstoffröhren |
| **4. Großgeräte** | > 50 cm | Server, Drucker, Kopierer |
| **5. Kleingeräte** | < 50 cm | PCs, Laptops, Tablets, Smartphones |
| **6. Kleine ITK-Geräte** | ITK < 50 cm | Router, Switches, Access Points |

**Pflichten nach ElektroG:**

| Pflicht | Beschreibung | Verantwortlich |
|---------|--------------|---------------|
| **Rücknahmepflicht** | Alte Geräte zurücknehmen | Händler, Hersteller |
| **Sachgerechte Entsorgung** | Entsorgung über zertifizierte Entsorger | Unternehmen |
| **Datenlöschung** | Daten vor Entsorgung löschen | Unternehmen |
| **Dokumentation** | Entsorgung dokumentieren | Unternehmen |
| **Meldepflicht** | Bei Stiftung EAR registrieren | Hersteller |

**BattG (Batteriegesetz):**

| Pflicht | Beschreibung |
|---------|--------------|
| **Rücknahmepflicht** | Alte Batterien zurücknehmen |
| **Sammelbehälter** | Sammelbehälter bereitstellen |
| **Sachgerechte Entsorgung** | Entsorgung über zertifizierte Entsorger |
| **Kennzeichnung** | Symbol auf Batterien (durchgestrichene Mülltonne) |

**VerpackG (Verpackungsgesetz):**

| Pflicht | Beschreibung |
|---------|--------------|
| **Registrierung** | Bei Zentrale Stelle Verpackungsregister registrieren |
| **Systembeteiligung** | Bei dualen Systemen beteiligen |
| **Kennzeichnung** | Verpackungen kennzeichnen |

**Datenlöschung vor Entsorgung:**

| Methode | Beschreibung | Sicherheit |
|---------|--------------|------------|
| **Löschen** | Dateien löschen | Nicht sicher (wiederherstellbar) |
| **Formatieren** | Festplatte formatieren | Nicht sicher (wiederherstellbar) |
| **Überschreiben** | Daten mehrfach überschreiben | Sicher (DOD-Standard) |
| **Physikalische Zerstörung** | Festplatte physisch zerstören | Sehr sicher |
| **Zertifizierte Löschung** | Professionelle Löschung | Sehr sicher (Zertifikat) |

**Visuelle Darstellung:**
```
Entsorgungsprozess:
    Gerät aussondern
         ↓
    Daten löschen
         ├── Überschreiben (DOD-Standard)
         ├── Physikalische Zerstörung
         └── Zertifizierte Löschung
         ↓
    Kategorie bestimmen
         ├── ElektroG-Kategorie
         ├── Batterien entfernen
         └── Verpackung trennen
         ↓
    Entsorgung
         ├── Zertifizierter Entsorger
         ├── Dokumentation
         └── Nachweis aufbewahren
```

**Praxis-Beispiel:**
Entsorgung von 20 alten PCs:

**Schritt 1: Geräte aussondern**
- 20 PCs werden ausgemustert
- Grund: Veraltet, nicht mehr einsatzfähig

**Schritt 2: Daten löschen**
- **Methode:** Zertifizierte Löschung durch externen Dienstleister
- **Standard:** DOD 5220.22-M (3-faches Überschreiben)
- **Dokumentation:** Löschzertifikat für jeden PC
- **Kosten:** 10€ pro PC = 200€

**Schritt 3: Kategorisierung**
- **ElektroG-Kategorie:** 5. Kleingeräte (< 50 cm)
- **Batterien:** CMOS-Batterien entfernen (separate Entsorgung)
- **Verpackung:** Verpackungsmaterial trennen

**Schritt 4: Entsorgung**
- **Entsorger:** Zertifizierter Entsorger (zertifiziert nach ElektroG)
- **Transport:** Abholung durch Entsorger
- **Dokumentation:** Entsorgungsnachweis erhalten
- **Kosten:** 5€ pro PC = 100€

**Schritt 5: Dokumentation**
- Löschzertifikate archivieren
- Entsorgungsnachweise archivieren
- Nachweis für 5 Jahre aufbewahren

**Gesamtkosten:** 300€ (200€ Löschung + 100€ Entsorgung)

**Alternative: Spende an gemeinnützige Organisation**
- Daten löschen (obligatorisch)
- PCs spenden (steuerlich absetzbar)
- Keine Entsorgungskosten
- Sozialer Nutzen

**Prüfungscheck:**
**Frage:** Welche Gesetze müssen bei der Entsorgung von IT-Geräten beachtet werden? Beschreiben Sie die wichtigsten Pflichten.

**Antwort:**
**Relevante Gesetze:**

1. **ElektroG (Elektro- und Elektronikgerätegesetz):**
   - Regelung der Entsorgung von Elektrogeräten
   - Kategorisierung (6 Kategorien)
   - Sachgerechte Entsorgung über zertifizierte Entsorger
   - Dokumentation der Entsorgung

2. **BattG (Batteriegesetz):**
   - Regelung der Entsorgung von Batterien und Akkus
   - Rücknahmepflicht
   - Sammelbehälter bereitstellen

3. **VerpackG (Verpackungsgesetz):**
   - Regelung der Entsorgung von Verpackungen
   - Registrierung bei Zentrale Stelle
   - Systembeteiligung

4. **DSGVO (Datenschutz-Grundverordnung):**
   - Datenlöschung vor Entsorgung
   - Schutz personenbezogener Daten

**Wichtigste Pflichten:**

1. **Datenlöschung:** Daten vor Entsorgung sicher löschen (überschreiben, zerstören, zertifizierte Löschung)
2. **Sachgerechte Entsorgung:** Entsorgung über zertifizierte Entsorger
3. **Dokumentation:** Entsorgungsnachweise aufbewahren (5 Jahre)
4. **Kategorisierung:** Geräte nach ElektroG-Kategorien einordnen
5. **Batterien trennen:** Batterien vor Entsorgung entfernen

**Merksatz:**
"Entsorgung = Daten löschen → Kategorie bestimmen → zertifiziert entsorgen → dokumentieren - gesetzeskonform handeln!"
